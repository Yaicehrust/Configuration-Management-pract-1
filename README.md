# VFS Shell Emulator

Эмулятор UNIX-подобной командной оболочки для практической работы по
дисциплине «Конфигурационное управление», вариант №1.

## Возможности

Проект развивается по пяти этапам практической работы.

### Этап 1 — REPL

- графический интерфейс на Tkinter;
- заголовок окна содержит `VFS`;
- разбор команд с поддержкой кавычек;
- заглушки `ls` и `cd`;
- команда `exit`;
- обработка ошибок парсинга и неизвестных команд.

### Этап 2 — Конфигурация

- параметры запуска `--vfs` и `--script`;
- отладочный вывод параметров при старте;
- стартовый скрипт команд эмулятора;
- комментарии в скриптах по синтаксису Python (`#`);
- вывод ввода и результата выполнения каждой строки;
- несколько `.bat`-сценариев для запуска эмулятора.

### Этап 3 — VFS

- загрузка VFS из CSV;
- дерево файлов и каталогов хранится только в памяти;
- вложенные элементы задаются абсолютными путями;
- содержимое файлов хранится в `content_base64`;
- подготовлены минимальная, расширенная и трёхуровневая VFS;
- ошибки отсутствующего файла, CSV-формата и base64 обрабатываются.

### Этап 4 — Основные команды

- `ls`;
- `cd`;
- `du`;
- `cal`.

### Этап 5 — Дополнительные команды

- `chown` — изменение владельца только в памяти;
- `vfs-load путь` — загрузка новой VFS из CSV без изменения исходного файла;
- подготовлены сценарии тестирования и ошибок.

## Требования

Python 3.12+ и Tkinter. Сторонние библиотеки не требуются.

## Структура проекта

```text
src/     исходный код
  app.py          GUI
  commands.py     команды
  config.py       параметры запуска
  main.py         точка входа
  parser.py       парсер команд

  vfs.py          виртуальная файловая система
```

Windows:

```text

```


## Формат VFS CSV

Используется CSV с заголовком:

```text
path,type,size,owner,content_base64
```

`path` — абсолютный путь внутри VFS.

`type` — `dir` или `file`.

`size` — размер файла в байтах. Для каталогов используется `0`.

`owner` — владелец элемента.

`content_base64` — данные файла в Base64. Для каталогов поле пустое.

Например:

```text
path,type,size,owner,content_base64
/,dir,0,root,
/home,dir,0,root,
/home/user,dir,0,user,
/home/user/readme.txt,file,12,user,SGVsbG8gV29ybGQhCg==
```

Вложенность представляется полными путями. Для каждого родительского
каталога должна существовать соответствующая строка `dir`; порядок строк
в CSV не важен.

## Команды

### `ls`

```text
ls
ls PATH
ls -l
ls -l PATH
```

Без аргументов показывает содержимое текущего каталога. Опция `-l` выводит
тип, размер и владельца. Для файла выводится сам файл.

### `cd`

```text
cd
cd PATH
```

Переходит в указанный каталог. Поддерживаются `/`, относительные пути и
`..`. Команда без аргумента возвращает в корень VFS.

### `du`

```text
du
 du PATH
 du -s PATH
 du -h PATH
 du -s -h PATH
```

Показывает размеры файлов и каталогов. `-s` оставляет только итог для
указанного пути, `-h` включает человекочитаемый формат.

### `cal`

```text
cal
cal MONTH YEAR
cal YEAR
```

Показывает календарь текущего месяца, заданного месяца и года либо всего
указанного года.

### `chown`

```text
chown OWNER PATH
chown -R OWNER PATH
```

Меняет владельца в объекте VFS в памяти. `-R` применяет изменение к
каталогу и его содержимому. Исходный CSV не изменяется.

### `vfs-load`

```text
vfs-load PATH
```

Загружает новую VFS из CSV. После загрузки текущий каталог становится `/`.

### `exit`

```text
exit
```

Закрывает приложение.

## Стартовый скрипт

Стартовый скрипт содержит одну команду в строке. Пустые строки и строки,
начинающиеся с `#`, пропускаются. На экране отображается и исходный ввод,
и результат его выполнения.
